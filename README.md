# SLTA プロフィールグラフ作成ツール

標準失語症検査（SLTA）の結果を1問ずつ段階（6〜1）で入力すると、正答率と段階別件数のプロフィールを自動で描く、言語聴覚士向けのツールです。

- 作成：KENTA SHINKAWA
- 1ファイル（index.html）だけで動きます。外部との通信はしません。
- 入力したデータは、使っている人のブラウザの中にだけ保存されます。サーバーには送られません。

## 主な機能
- 1問ずつのマス入力（数字キーで自動送り、0／x＝中止）
- 評価5回分の重ね描き、段階別件数の表、前回との比較
- 問題ごとのメモ（反応・誤りの種類・ヒント）
- 患者情報・検査情報（年齢、所要時間、発症からの期間を自動計算）
- 印刷、白紙の記録用紙の印刷、グラフの画像保存、CSV保存

## 注意
- SLTAの検査用具・マニュアル・記録用紙の内容（刺激語など）は含みません。
- 非失語症者の基準値は同梱していません。利用者が学会のソフトウェアやマニュアルの値を、設定から読み込んでください。
