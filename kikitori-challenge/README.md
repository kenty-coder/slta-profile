# ききとりチャレンジ

失語症の方のための、聞いて覚える練習（言語性短期記憶）のウェブアプリです。
スマホ・タブレットのブラウザで使います。作成者：KENTA SHINKAWA

## できること
- 単語コース／数字コース／文章コース（混ぜずに選ぶ）
- 指さしで答える／用紙に書いて答える（用紙はアプリから A4 で印刷）
- 1回10問。8問以上正解で次のレベルへ、6問以下でひとつ前のレベルへ
- 記録は端末の中だけに保存（コースごと別々。アプリを更新しても消えません）

## 公開のしかた（GitHub Pages）
1. GitHub で空のリポジトリを作り、このフォルダの中身をすべて入れる
2. リポジトリの Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に表示される URL を患者さんの端末で開く

内容を更新して GitHub に入れ直すと、患者さんが次に開いたとき自動で新しくなります。

## 音声ファイルの作り方（Microsoft Azure 音声合成）
パソコンに Node.js（22以上）を入れ、このフォルダで次を実行します。キーはファイルに書かないでください。

```bash
AZURE_SPEECH_KEY=（Azureのキー） AZURE_SPEECH_REGION=japanwest node tools/generate-audio.mjs
```

続けて `bash tools/trim-silence.sh` を実行し、前後の余分な無音を切りそろえます（ffmpeg が必要）。

`audio/` フォルダに128個の音声ができるので、それも GitHub に入れます。
音声ファイルが無いあいだは、端末の読み上げ機能が仮に代読します。

## 単語を増やすとき
`js/data.js` に1行足し、同じ名前の絵を `img/w/` に置き、上の音声づくりをもう一度実行します。
